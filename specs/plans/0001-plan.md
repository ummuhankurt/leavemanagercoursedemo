## Risks & open questions

- **R-1 Ortam (R-13).** doctor bugün: `0 fail, 1 warn` (check.conf'ta adım yok → profil hükmü
  yok). Adım 4'ten sonra `requires` satırları `uv --version` ve `uv python find 3.13` olacak; bu
  makinede uv yok → **fast ve full profil burada çalıştırılamaz**. Önerim: ortamı düzeltmek —
  `winget install --id=astral-sh.uv -e`, sonra `uv python install 3.13` (uv'nin kendi Python'u;
  sistemdeki 3.10'a dokunmaz). Gerekçe: BUILD her adımda `--fast` çalıştırmalı; yalnızca CI'a
  bırakmak iç döngüyü öldürür.
- **R-2 Alembic ertelensin.** Bu spec'te tablo yok; boş bir migration altyapısı kullanılmayan kod
  olur. Önerim: Alembic, ilk tablolu spec'te (kullanıcılar/izin türleri) gelsin; `docs/testing.md`
  "migration'ları uygulanmış" kuralı o zaman devreye girer. Bugün entegrasyon testi geçici bir
  SQLite dosyasıyla çalışır.
- **R-3 Yeni bağımlılıklar** (`docs/security.md` Dependencies — bu planın onayı onları da onaylar):
  çalışma: `fastapi` (MIT), `uvicorn` (BSD-3), `sqlalchemy` (MIT); geliştirme: `pytest` (MIT),
  `httpx` (BSD-3, TestClient için), `ruff` (MIT), `mypy` (MIT), `import-linter` (BSD-2),
  `pip-audit` (Apache-2.0). Hepsi son 12 ayda sürüm çıkarmış, yaygın paketler.
- **R-4 "DB erişilemiyor" nasıl üretilir (AC-2).** Önerim: testte DB URL'si var olmayan bir klasördeki
  SQLite dosyasını gösterir → bağlantı gerçekten başarısız olur. Gerekçe: mock yok, deterministik,
  gerçek hata yolunu sınar.
- **R-5 Sürüm kaynağı (G-3).** `importlib.metadata.version("leave-manager")` — `pyproject.toml`'daki
  sürüm; kodda sabit yok.
- **R-6 UI durumlarının otomatik testi yok.** AC-4/AC-5 davranışı JS'te; bootstrap kararıyla JS test
